# 🎓 GECA Academic Planner — Web Application

A browser-based academic utility project with student onboarding, login-related pages, and SGPA/CGPA calculation interfaces.

## ✨ Project Areas
- SGPA/CGPA-related academic tools
- Student onboarding and login flows
- Firebase-related client configuration
- Browser-based user interface

## 🧰 Tech Stack
- HTML
- CSS
- JavaScript
- Firebase (as configured in the source)

## 🚀 Getting Started
1. Clone the repository.
2. Open the HTML entry point in a browser or use a local web server.
3. Review Firebase configuration before enabling authentication.
4. Never commit private keys, credentials, or production secrets.
